Yang diperlukan untuk run social_media.py:
- python 3.12.10
- joblib
- pandas
- streamlit
- scikitlearn 1.6.1

Alternatif jika tidak mau ganti python 3.12.10 sebagai versi global:
-Install python 3.12.10 dan buatkan virtual environment/venv dengan input kode dibawah di terminal:
```text
py -3.12 -m venv [Nama Virtual Environment]
[Virtual Environment]\Scripts\activate <--- untuk pasang virtual environmentnya
```

-Download library yang diperlukan saat venv diaktifin
-Run social_media.py
